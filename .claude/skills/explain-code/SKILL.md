# Explain Code Skill

## Description
Provides detailed, easy-to-understand explanations of code segments.

## Usage
Invoke this skill when you need to understand how code works.

## What You Get
1. **Purpose**: What the code does and why
2. **Flow**: Step-by-step execution flow
3. **Dependencies**: What other components it uses
4. **Examples**: Real-world analogies
5. **Diagrams**: Visual representation when helpful

## How to Use
Simply ask to explain any code file, method, or concept:
- "Explain the SubscriptionService"
- "How does JWT authentication work here?"
- "What does this method do?"

## Output Format
- Clear, jargon-free language
- Code snippets with highlights
- ASCII diagrams when helpful
- Real-world analogies
- Related components and files

## Best For
- Understanding unfamiliar code
- Learning new patterns
- Code reviews
- Documentation
- Onboarding
