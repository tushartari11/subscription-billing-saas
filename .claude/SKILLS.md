# Available Skills

## Explain Code Skill

**Usage**: Use when you need detailed explanation of code functionality

**What it does**:
- Explains code purpose and functionality
- Identifies design patterns used
- Shows dependencies and interactions
- Suggests potential improvements
- Provides examples and analogies

**When to use**:
- Understanding unfamiliar code
- Learning how a feature works
- Reviewing code for clarity
- Onboarding new team members
